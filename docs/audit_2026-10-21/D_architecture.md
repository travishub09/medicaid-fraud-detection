Date: 2026-10-21. Scope: structure, hard-rule compliance, duplication, error handling, tests, configuration/runners, guardrails, the two model tracks. Adapter column contracts, feature wiring and the label chain are out of scope (other reviewers). Read-only; every claim is grep- or line-cited. `src/attempt_1` is excluded from compliance counts (deprecated by CLAUDE.md) unless stated.

## (d) Findings, ranked

**HIGH**

- **F1. Derived data committed, gitignore bypassed.** `src/backtest/backtest_results.csv` (31,270 company rows, 53 with matched excluded NPIs and exclusion dates) and `backtest_report.json` are tracked (`a5cb75a`) against `.gitignore:*.csv` and CLAUDE.md rule 7 "never force-add data files". *Fix:* `git rm --cached` both, regenerate into `<data_root>/backtest/`, and add a pre-commit hook that refuses any tracked `*.csv/*.parquet/*.json` outside `docs/reminders.json`.
- **F2. The m:1 guarantee is enforced by silent dedup, not by assertion.** Eight `drop_duplicates("npi")`-then-`merge` sites in `provider_features_export.py` (:349, :378, :393, :458, :486, :515, :525, :1064) and the un-validated org-grain broadcast (:263-265) mean a duplicated adapter row is discarded without a quarantine write or a raise; 5 of 119 merges use `validate=`. *Fix:* one `join_m1(left, right, on, source)` helper that asserts `right[on].is_unique`, writes the duplicates to `_quarantine/<source>_dups.parquet`, and merges with `validate="m:1"`; replace the eight sites and `_broadcast_org_to_npi`.
- **F3. Result-changing silent fallbacks.** `entity_graph/graph_embeddings.py:116-121` returns `{}` when `nx.pagerank` raises, so `graph_fraud_proximity` goes empty with no log line; `model_a/address_grounding.py:109-114` drops `addr_geocoded`/`addr_no_match` entirely on any geocoder error; `scheme_triage.py:168-172` returns an empty registry; `duck.py:80-86` silently runs without a temp directory if `SET` fails (the exact failure the module exists to prevent). *Fix:* every swallowed exception on a feature path must emit to the run's SOURCES_REPORT/manifest (`status: failed, reason`) — the mechanism already exists for adapters.
- **F4. Stage 1 drops malformed raw rows with no count.** `clean_data.py:221-222` and `:271-272` read the spending CSV with `ignore_errors=true`; the first conservation count (`:508-514`) starts from `spending_clean`, so the raw→parquet step has no row-count assertion and no quarantine. Same at `ingest_cms/docgraph.py:92`. *Fix:* count raw lines (DuckDB `read_csv_auto(..., ignore_errors=false)` into a `rejects` table via `store_rejects=true`, DuckDB ≥0.10) and assert `rows_parquet + rows_rejected == rows_raw`, writing rejects to quarantine.
- **F5. Runner drift: the Makefile training targets violate the project's own rule.** `Makefile:79-84` (`provider-features`) and `:129-134` (`frozen-package`) carry no `--case-db` / `--defendant-npis` (CLAUDE.md: "every training runner's export line carries" them; the v8/v9 HOLDs were exactly this omission), and the `frozen-package` graph step (:127-128) passes no `--asof-nppes` (the v6 lesson). `ops/vm/run_frozen_night.sh:103` is the only runner with the full flag set; the `.bat` family is untracked. *Fix:* make the shell runner the single definition (`ops/run_frozen.sh`), have `make frozen-package` call it, and commit the Windows wrapper as a thin `call bash` or delete it.
- **F6. The `src/model` track is a parallel universe.** `model/config.py:12` hard-codes `~/Desktop/Data` (capital D, ignores `MEDICAID_DATA_ROOT`); label `provider_on_leie` vs model_a's `provider_on_exclusion`; `EXPECTED_PU_ROWS = 308_038`, `EXPECTED_PU_POSITIVES = 578`, `EXPECTED_UNIVERSE_ROWS = 617_062` (:64-67) pin one vintage; zero tests reference the package; 4 of 7 modules are dead by the import/test/runner test; its own assert helper (`data.py:25`) and LightGBM fit (`train.py:140`); it imports `build_final_leads.normalize` (`screen_leads.py:26`), a third name normalizer. *Fix:* either retire it to `attempt_1`-style reference status in CLAUDE.md, or port it onto `model_a.company_list`/`network_ab._fit_predict` and the shared root resolver.
